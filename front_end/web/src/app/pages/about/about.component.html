Questions fréquentes

Ce qu’il faut savoir avant de commencer

question_mark

AquaManager est-il gratuit ?

Oui. La formule Classic permet de suivre gratuitement jusqu’à deux aquariums avec les mesures, le calendrier, les protocoles et l’assistant intelligent.

question_mark

Quels paramètres puis-je suivre ?

Vous pouvez notamment enregistrer le pH, le GH, le KH, les nitrites, les nitrates, la température et plusieurs paramètres spécifiques à votre type d’aquarium.

question_mark

L’application remplace-t-elle les tests d’eau ?

Non. Vous continuez à mesurer l’eau avec vos tests habituels. AquaManager organise les résultats et vous aide à comprendre leur évolution.

question_mark

Puis-je gérer plusieurs aquariums ?

Oui. Classic permet deux aquariums, Premium jusqu’à cinq et Pro ne limite pas le nombre de bacs.
