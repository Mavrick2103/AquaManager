Journaux complets du serveur

Pour investiguer un incident, exécutez ces commandes sur le VPS, depuis le dossier AquaManager. Les journaux Docker ne sont pas exposés dans le navigateur. 

docker compose logs --since=1h --tail=200 api
docker compose logs --since=1h --tail=200 frontend ssr
docker compose ps
