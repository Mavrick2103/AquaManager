Comment lire ces chiffres ?

Ces indicateurs sont reconstruits à partir des données conservées : supprimer un aquarium, une mesure ou une tâche peut modifier l’historique. Une ouverture des Solutions indique une consultation, pas une recommandation appliquée. Les tâches comptées sont créées, pas forcément réalisées. Les mois récents ont moins de recul.

Les visites de l’offre Premium, les motifs de résiliation et l’origine des inscriptions ne sont pas encore enregistrés dans ce tableau.
